Architecture & Precedence Matrix P2 System Specification

1. Single Classification at Fireable Boundaries

The router invokes request_classifier.classify(input) exactly once during Phase::Switch and Phase::ColdStart in Mode::FreeFlowing. Continuation and tool-turn sequences (Phase::Continue) hit the Level 2 sticky cache and never trigger classification.

2. Thompson Sampling Consumption

The resulting Classification.request_type is passed directly into classifier::pick_model_thompson. The legacy regex classification call has been removed from the hot path.

3. Automatic Fallback Guarantee

When using HostedClassifier, any HTTP timeout, network disconnect, malformed JSON, or non-200 status code automatically degrades to RegexClassifier. The system never panics or aborts a request.
