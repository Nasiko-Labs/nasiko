⚡ What we changed in the Nasiko router

Two upgrades, shown before → after · numbers below come from the real Rust code and the live app · open the detailed dashboard →

Both improvements run inside the real router. This page shows, in plain terms, what each one does and how much it saves.

P1 · Compact tool schemas

fewer prompt tokens
  • Before: every tool was sent as verbose JSON Schema on every call.
  • After: tools are sent as a compact one-line signature grammar.
  • Same tool calls, fail-closed decoding — −30–55% of the tool-schema bytes.
  • Recorded per call in token_usage.metadata.compact.

P2 · Request classifier

smarter routing
  • Before: a flat regex — fixed complexity 3, fixed confidence 0.5.
  • After: a real complexity (1–5) + calibrated confidence.
  • Now drives the Level-3 model tier (regex stays the fallback).
  • Pluggable RequestClassifier trait — swap in any backend.
